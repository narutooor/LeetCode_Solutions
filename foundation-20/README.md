## Lesson plan and authoritative progress

## Closeout protocol for every lesson

1. Teach one concept and obtain the learner's own response or demonstrable implementation.
2. Record actual evidence and gaps, explicitly separating **explained** from **understood / independently demonstrated**.
3. Commit substantive notes / code / verified tests to GitHub.
4. Update `Foundation_20` and, where appropriate, the existing `Science_120` / `Session_Log` / `Change_Log`.
5. Cross-check both records; report connection or write failures explicitly.

Clinical patient data, credentials and unpublished collaborator research must never be uploaded to this public repository.
