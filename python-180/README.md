# Python 180 — LLM Research Scientist Coding Track

This directory holds the **Python interview practice track** associated with the Google Sheets 340-item research-scientist training ledger.

**Learning evidence is not the same as mastery.** Progress is tracked using *practiced*, *independently passed*, and *mastered* states. Never fabricate tests, solutions, dates, or scores.

## Layout

- `solutions/`: independently written solutions, named `lcXXXX_slug.py`
- `tests/`: independently executed Python tests, named `test_lcXXXX.py`
- `reviews/`: failed attempts, corrective hints, invariants, complexity and spaced-review notes
- `SESSION_TEMPLATE.md`: mandatory evidence template

## Every-session closeout

1. Record the problem ID, attempt date, source and independent / hinted status.
2. Run the actual Python interpreter; record the command and PASS/FAIL outcomes, and full traceback for errors.
3. Preserve the submitted solution **as the student's work**, not an invented replacement. Do not prematurely publish full solutions when the student requested hints only.
4. Commit only substantive results to this repository; record the exact commit SHA or file link.
5. Update the Google Sheets `Coding_180`, `Session_Log` and, if needed, `Review_Queue` tabs with the GitHub link and next review.
6. Re-read and confirm both GitHub commit and Google Sheets row. If either write failed, report it explicitly.
7. Never commit clinical-trial data, personal information, credentials, or unpublished collaborator research without authorization.
